# 记忆银行

一个证据驱动、可恢复、有人类确认的家庭记忆 Agent。**当前仓库只保留产品构想与决策文档**，代码实现将从零开始，方向是**小程序**（不做 Web 应用）。

## 产品构想

中年子女希望保存长辈的声音和人生故事，但微信录音、转写工具和文档分散，老人操作困难，整理结果也可能丢失原声依据或被 AI 过度改写。

要证明的可信闭环：

> 老人讲述 → Agent 查漏补缺 → 七要素结构化 → 温和追问 → 带来源标识的故事卡片 → 家人确认

## 不可破坏的产品规则

- **老人意愿优先**：明确表达停止时立即结束，不再追问。
- **采集阶段不补造事实**：AI 只提取、标记、追问。
- **七要素缺失即留空**，不得猜测；缺失项进入 `missing_fields`。
- **AI 生成或整理的内容必须显式标注**，草稿永远停留在“待确认”，不自动发布。
- **证据可追溯**：原声、转写、提取事实之间保留来源关系。
- **发布需老人与创建者确认**，家人补充内容单独确认。
- **情绪只允许粗粒度、非医学描述**，不得作诊断。
- **撤回即停止使用并隐藏内容**，支持进一步彻底删除。
- **密钥、录音、转写和个人信息**不得进入日志、测试夹具与版本库。

## 关于旧实现

仓库早期包含一版 Web 版 MVP（LangGraph 五子图主流程 + Mock 智能节点 + SQLite 存储 + 演示页面 + 产品化后端与测试），现已全部移除，只保留文档。

旧代码仍可从 Git 历史找回：

```powershell
git switch backup/mvp-full-snapshot   # 或 git show snapshot-mvp-full
```

确认不再需要后，可彻底清理：

```powershell
git branch -D backup/mvp-full-snapshot
git tag -d snapshot-mvp-full
git reflog expire --expire=now --all
git gc --prune=now --aggressive
```
