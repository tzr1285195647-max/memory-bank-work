# 记忆银行

一个证据驱动、可恢复、有人类确认的家庭记忆 Agent。项目采用**微信原生小程序 + FastAPI + LangGraph + SQLite**，当前正在推进可供评委完整体验的 P0 演示闭环。

## 产品构想

中年子女希望保存长辈的声音和人生故事，但微信录音、转写工具和文档分散，老人操作困难，整理结果也可能丢失原声依据或被 AI 过度改写。

要证明的可信闭环：

> 老人讲述 → Agent 查漏补缺 → 七要素结构化 → 温和追问 → 带来源标识的故事卡片 → 家人确认

## 不可破坏的产品规则

- **老人意愿优先**：明确表达停止时立即结束，不再追问。
- **采集阶段不补造事实**：AI 只提取、标记、追问。
- **七要素缺失即留空**，不得猜测；缺失项进入 `missing_fields`。
- **AI 生成或整理的内容必须显式标注**，草稿永远停留在“待确认”，不自动发布。
- **证据可追溯**：原声、转写、提取事实之间保留来源关系。
- **发布需老人与创建者确认**，家人补充内容单独确认。
- **情绪只允许粗粒度、非医学描述**，不得作诊断。
- **撤回即停止使用并隐藏内容**，支持进一步彻底删除。
- **密钥、录音、转写和个人信息**不得进入日志、测试夹具与版本库。

真机调试可通过同一局域网连接电脑上的本机后端：开发者工具使用 `127.0.0.1`，手机使用 `config.js` 中的 `deviceBaseUrl`。网络环境变化后需同步更新电脑 IPv4。

开发者工具连接本机后端且已配置腾讯云 ASR 时，录音完成后可自动转写并进入人工校对；未配置或真机离线演示时会使用明确标注的演示转写。生成前可选择“原味口述 / 自然整理 / 适合成书”，系统会依次展示文字整理、要点提取和原声核验进度。

家庭协作已形成闭环：家人可提交“补充回忆 / 修改建议”，但不能改写或发布故事；长辈逐条采纳或忽略后，才能完成最终确认。

“我的 → 隐私与操作记录”提供本机可演示的治理中心：展示数据使用边界，并按故事、家庭协作、原声和隐私授权筛选操作记录；记录不包含故事正文、转写内容或录音地址，删除内容后仍保留。

故事书支持全文搜索与“家庭纪念册”交付：可修改书名、查看封面/年代目录/连续阅读，并把经过确认的故事复制为完整文本。家庭管理提供 24 小时本机邀请码和清晰的长辈/家人权限说明；双人访谈可逐轮人工标注讲述者。首次录音会先说明原声用途与撤回方式。

## 技术选型（已定）

- **微信原生小程序**，单个小程序内按 02 屏分流「长辈 / 家人」身份
- **思源宋体子集**在线加载（设计中文字形实际来自 fallback，非 Lora）
- 录音 `wx.getRecorderManager()`，播放 `wx.createInnerAudioContext()`
- 腾讯云录音文件识别（密钥仅由本机 FastAPI 读取），识别结果必须人工校对后才能进入 Agent 流程

## 本地运行

1. 将 `.env.example` 复制为 `.env`；保持 `AGENT_MODE=mock` 即使用确定性离线智能体。需要真实转写时填写 `TENCENTCLOUD_SECRET_ID` 与 `TENCENTCLOUD_SECRET_KEY`。
2. 创建 Python 虚拟环境并安装 `backend/requirements.txt`。
3. 启动后端：`python backend/run.py`。本机演示使用 `HOST=0.0.0.0`，允许同一局域网内的测试手机访问。
4. 使用微信开发者工具打开本目录，并在本地开发阶段关闭合法域名校验。

## 队友接手

1. 克隆仓库后，将 `.env.example` 复制为 `.env`。`.env` 已被 Git 忽略，腾讯云和模型密钥需要每位开发者在自己电脑上填写，不能通过 GitHub 传递。
2. 运行 `python -m venv .venv`，激活虚拟环境后执行 `pip install -r backend/requirements.txt`。
3. 启动后端：`python backend/run.py`。需要真机访问时，把 `config.js` 的 `deviceBaseUrl` 改为当前电脑的局域网 IPv4，手机和电脑需处于同一网络。
4. 使用微信开发者工具导入仓库根目录；本地或真机调试阶段勾选“不校验合法域名”。
5. 默认 `AGENT_MODE=mock`，不需要大模型密钥；腾讯云录音转写需要在本机 `.env` 中填写对应密钥并开通录音文件识别服务。

开发检查：

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests -q
python design/source/verify_project.py
python design/source/verify_code.py
```
