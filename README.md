# 记忆银行

一个证据驱动、可恢复、有人类确认的家庭记忆 Agent。项目采用**微信原生小程序 + FastAPI + LangGraph + SQLite**，当前正在推进可供评委完整体验的 P0 演示闭环。

## 产品构想

中年子女希望保存长辈的声音和人生故事，但微信录音、转写工具和文档分散，老人操作困难，整理结果也可能丢失原声依据或被 AI 过度改写。

要证明的可信闭环：

> 老人讲述 → Agent 查漏补缺 → 七要素结构化 → 温和追问 → 带来源标识的故事卡片 → 家人确认

## 不可破坏的产品规则

- **老人意愿优先**：明确表达停止时立即结束，不再追问。
- **采集阶段不补造事实**：AI 只提取、标记、追问。
- **七要素缺失即留空**，不得猜测；缺失项进入 `missing_fields`。
- **AI 生成或整理的内容必须显式标注**，草稿永远停留在“待确认”，不自动发布。
- **证据可追溯**：原声、转写、提取事实之间保留来源关系。
- **发布需老人与创建者确认**，家人补充内容单独确认。
- **情绪只允许粗粒度、非医学描述**，不得作诊断。
- **撤回即停止使用并隐藏内容**，支持进一步彻底删除。
- **密钥、录音、转写和个人信息**不得进入日志、测试夹具与版本库。

“我的 → 隐私与操作记录”提供本机可演示的治理中心：展示数据使用边界，并按故事、家庭协作、原声和隐私授权筛选操作记录；记录不包含故事正文、转写内容或录音地址，删除内容后仍保留。

故事书支持搜索、重新编辑和单条删除；家庭纪念册的正式分享与文件导出暂缓。记忆碎片保存在本机后端，支持跨账号读取、编辑、删除、上下排序和移动主题。首次录音会先说明原声用途与撤回方式。

## 技术选型（已定）

- **微信原生小程序**，单个小程序内按 02 屏分流「长辈 / 家人」身份
- **思源宋体子集**在线加载（设计中文字形实际来自 fallback，非 Lora）
- 录音 `wx.getRecorderManager()`，播放 `wx.createInnerAudioContext()`
- 腾讯云录音文件识别（密钥仅由本机 FastAPI 读取），识别结果必须人工校对后才能进入 Agent 流程

## 本地运行

1. 将 `.env.example` 复制为 `.env`。首次离线安装可保持 `AGENT_MODE=mock`；真实演示改为 `AGENT_MODE=llm` 并填写自己的模型密钥。需要腾讯云转写时另填 ASR 密钥。
2. 创建 Python 虚拟环境并安装依赖：`python -m venv .venv`、`.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt`。
3. 启动后端：`.\.venv\Scripts\python.exe backend\run.py`。开发者工具使用默认 `HOST=127.0.0.1`；手机真机调试时改为 `HOST=0.0.0.0`，并把 `config.js` 的 `deviceBaseUrl` 改为这台电脑的局域网 IPv4。
4. 使用微信开发者工具打开仓库根目录，并在本地开发阶段关闭合法域名校验；手机和电脑需处于同一局域网。

## 队友接手

1. 克隆仓库后，在仓库根目录执行 `Copy-Item .env.example .env`。`.env` 已被 Git 忽略，腾讯云和模型密钥需每位开发者在自己的电脑上填写，不能通过 GitHub 传递。
2. 执行 `python -m venv .venv`，然后执行 `.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt`。
3. 按“本地运行”配置 `HOST` 和 `config.js` 的 `deviceBaseUrl`，执行 `.\.venv\Scripts\python.exe backend\run.py`；手机与电脑需在同一局域网。
4. 使用微信开发者工具导入仓库根目录；本地或真机调试阶段勾选“不校验合法域名”。
5. 正式演示使用 `AGENT_MODE=llm`；登录后查询 `/api/agent/status`，确认 `configuredMode=llm`、`llmEnabled=true`，且正常流程不持续增加 `fallbackCount`。
6. Git 只同步代码，不同步本机 SQLite 数据库、录音、历史转写或已发布故事；新电脑首次启动会初始化自己的本机演示账号和空数据。请勿复制他人的 `.env` 或原声文件到仓库。

当前待修复：由勾选碎片生成的故事，在预览页点击“确认故事”时仍可能错误请求不存在的采访会话。该草稿会保留，但正式真机演示完整发布流程前需修复并复测。
