# 记忆银行

一个面向家庭口述记忆的微信小程序：长辈录音，腾讯云 ASR 转写，五个核心 Agent 协助校对、提取证据、温和追问、写作和审计；同一家庭的成员可代为审核确认，但讲述者始终属于原录音者。当前目标是**本机后端 + 微信开发者工具 / 同局域网真机**的演示，不是公网服务。

> 项目规则以 [agent.md](agent.md) 为准。当前代码仍有待修复项，见文末“已知限制”；不要把待确认草稿当作已发布故事。

## 当前能做什么

- 四个本机演示账号、注册、密码登录、固定验证码演示登录，同一家庭内跨账号共享。
- 微信录音、腾讯云真实 ASR、人工填写与校对。转写失败时保留录音，可重试或人工填写，**不会自动填入演示文字**。
- 多段记忆碎片的保存、勾选、编辑、删除、排序和移动；显示原讲述者与确认人。四个推荐主题之外，也可以创建家庭专属的自定义主题。
- 两种故事整理风格：`raw / 原味口述`、`book / 适合成书`。旧故事若已存为“自然整理”，仍按原标签展示，不删除或改写历史内容。
- 故事草稿、逐句证据、事实审计、家庭建议、家庭成员审核、故事列表与操作记录。只有原讲述者可续录同一故事。
- 家庭纪念册按年份翻页阅读；可将已确认故事导出为带静态装饰插画的 PDF，在微信中打开。未确认草稿和录音不进入 PDF。
- 故事预览中的多智能体协作记录：可查看处理步骤、模型/规则降级、证据和审计发现。
- LangGraph 采访会话通过 SQLite Checkpoint 暂停和恢复；后端重启后可继续尚未结束的采访。

## 五个核心 Agent

五个 Agent 是五种独立职责，**不要求五个模型或五把 API Key**。真实模式下，它们通过同一个 OpenAI 兼容模型接口、不同 Prompt 和结构化输出 Schema 工作。Prompt 目前直接定义在 [`backend/agents/llm.py`](backend/agents/llm.py)，输出模型在 [`backend/agents/schemas.py`](backend/agents/schemas.py)；目前没有独立且被代码加载的 Prompt Markdown 文件。

| Agent | 进入流程的时机 | 输出与硬约束 |
| --- | --- | --- |
| 口述校对 | 腾讯云 ASR 成功后 | 给出可编辑的清理建议及不确定项；`asrRawText` 原始转写、`agentCleanText` 建议、`confirmedText` 人工确认文本分开保存。Agent 不得覆盖原文或新增事实。 |
| 记忆证据 | 碎片文字经人确认后 | 提取时间、地点、人物、事件、结果、影响、感受七类事实；保存 `fragmentId`、`recordingId`、`narratorUserId` 和原文 `quote`。`quote` 必须是确认文字的真实子串；冲突并列保留。 |
| 采访提示 | 开始采访及每轮确认后 | 先读取同一讲述者、同一主题下已确认的历史碎片与事实，再结合本轮回答、缺失要素和已问问题生成下一问；已知要素与重复问题会被本地校验拦截。七要素齐全不等于故事足够详细：主动推荐生成需至少 7 段确认碎片、核心故事链完整且有足够原文细节，通常在 7–10 段间结束；讲述者仍可主动提前停止。 |
| 故事写作 | 用户勾选已确认碎片并选择风格后 | 只使用同一位讲述者的所选碎片，产出标题、正文、风格和句子级证据关系。混选林奶奶与王爷爷的碎片会被服务端拒绝。 |
| 事实审计 | 写作后及故事确认前 | 模型逐句检查新增人物、时间、地点、动作、结果、感受和关系变化；再叠加本地确定性证据规则。发现无依据内容时禁止发布，写作结果会尝试自动修订一次。 |

工作流由两部分组成：ASR 校对和已确认碎片的持久化证据抽取由 FastAPI 业务服务接入 Agent Provider；采访生成及勾选碎片生成均进入 [`backend/agents/graph.py`](backend/agents/graph.py) 的同一 LangGraph 父图，共用写作、事实审计和人工确认节点。业务库和 Checkpoint 均为 SQLite，模型调用失败时允许**有记录的规则降级**，但不能悄悄把前端虚构数据混进真实家庭数据。前端 `fallbackToMock=false`。

耗时操作使用后台任务与短轮询：校对、确认/编辑碎片、采访、生成和复审由后端执行，小程序每次只提交任务或查询进度，不再因为整条故事链超过 5 分钟而报超时。同一小程序会话内，网络恢复后重试会复用原任务；后端完成的结果保存在 SQLite。强制重启中断的运行中任务会明确报中断，不自动重放写入；请先刷新故事/碎片列表再继续，已保存内容和采访 checkpoint 不会清空。此实现面向当前单进程本机后端，暂不支持多个服务进程同时运行任务队列。

审计不仅检查引用是否存在，也逐个分句检查正文是否有原文依据；明显新增的年份和未澄清的跨碎片冲突不能直接发布。若有冲突，先回听原声、修正有误的确认碎片，再重新生成故事。故事预览会显示两段冲突原话；系统不会代替家人裁决。

可信边界：录音创建时确定 `narratorUserId`。小刘校对林奶奶的录音后，仍是“林奶奶的记忆”，可以另显示“小刘已确认”。只有 `confirmedText` 能成为事实与写作证据；AI 建议不等于用户原话，草稿不等于已发布故事。

采访上下文边界：开始新采访时从业务库读取**当前讲述者 + 当前主题**的已确认碎片；未确认转写、其他讲述者和其他主题不进入提示。页面编辑、确认、移动或删除碎片后，会重新建立采访会话，避免沿用过期问题。模型问到已知要素时会改用仍缺失的要素；后端不可用时不再把静态开场白标成“AI 采访提示”。

讲述入口保留四个推荐主题，也可输入 2–30 字创建自定义主题并直接开始讲述。自定义主题只在创建者家庭内可见，录音、采访上下文、碎片移动和故事沿用同一主题 ID；既有四主题及数据库内容不变。

## 技术结构

```text
微信原生小程序（pages / components / utils）
    ↓ 同机或局域网 HTTP；仅本地调试时关闭合法域名校验
FastAPI（backend/api.py、backend/routes/agent.py）
    ├── SQLite 业务库：账号、录音、三份转写、碎片事实、故事、审计日志
    ├── LangGraph + SQLite Checkpoint：采访问题、回答、暂停与恢复
    ├── Agent Provider：真实 LLM / 明示的规则降级
    └── 腾讯云 ASR：录音转写
```

录音、业务数据库、Checkpoint 和已生成内容存放在**运行后端的电脑**。启用腾讯云 ASR 与真实大模型时，必要的录音或文字会发送到相应厂商；不要对用户宣称“所有内容完全不上传公网”。Git 不同步 `.env`、数据库、录音或历史故事。

## 在队友电脑上运行（Windows / PowerShell）

1. 克隆仓库，在仓库根目录创建环境文件和 Python 虚拟环境（后端使用 `datetime.UTC`，**需要 Python 3.11 或更高**；若本机默认是 3.9/3.10，把下面的 `python` 换成 `py -3.11` 或 `py -3.12`）：

   ```powershell
   git clone https://github.com/tzr1285195647-max/memory-bank-work.git
   cd memory-bank-work
   Copy-Item .env.example .env
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
   npm ci
   ```

2. 在**自己的** `.env` 中配置模型和 ASR；不要把密钥发到群里、写入源码或提交到 Git。首次只验证页面时可保留 `AGENT_MODE=mock`，但这不代表真实模型已启用。真实五 Agent 演示至少需要：

   ```ini
   AGENT_MODE=llm
   LLM_API_KEY=填写你自己的密钥
   LLM_BASE_URL=https://api.deepseek.com
   LLM_MODEL=deepseek-chat
   TENCENTCLOUD_SECRET_ID=填写你自己的腾讯云 ID
   TENCENTCLOUD_SECRET_KEY=填写你自己的腾讯云 Key
   ```

   完整选项见 [`.env.example`](.env.example) 和 [模型配置说明](docs/LLM_SETUP.md)。单独填写 Key **不会**切换到真实模型；必须设置 `AGENT_MODE=llm` 并重启后端。模型网络、额度或输出异常会增加 `fallbackCount`，降级结果不能当成真实模型成功结果。

3. 启动后端：

   ```powershell
   .\.venv\Scripts\python.exe backend\run.py
   ```

   默认监听 `127.0.0.1:8787`，适合微信开发者工具。同局域网手机真机调试时，把 `.env` 改为 `HOST=0.0.0.0`，并把 [`config.js`](config.js) 的 `deviceBaseUrl` 改为**自己电脑的 IPv4**（现有地址仅适用于原开发电脑）。手机与电脑需在同一网络，并确认防火墙允许本机后端端口。
   后端默认**不自动重载代码**；更新代码后必须关闭旧进程并重新启动，再重新编译小程序。新版讲述页会检查后端是否返回历史碎片上下文，遇到旧版服务会明确提示，不再展示过时的 AI 问题。
   真机调试上传包只包含小程序代码及书页插画；`project.config.json` 已排除由后端 `/fonts` 提供的约 1 MB 字体、后端源码、测试、本地数据库和 `.env`。如果开发者工具仍提示 `source size exceeded max limit 2MB`，先重新编译并重试真机调试，确认已读取最新项目配置；不要删除字体源文件或数据库。

4. 用微信开发者工具导入仓库根目录。本机调试阶段在“详情 → 本地设置”关闭合法域名校验；这不等于已具备公网发布条件。首次启动会初始化本机数据库和四个演示账号，**不会**带来原开发电脑上的录音或故事。

5. 开发者可在演示前查询 `/api/agent/status`（接口需要登录令牌）；普通用户的“我的账户”页不展示模型配置和开发自检入口。真实模式应看到 `provider=llm-with-fallback`、`configuredMode=llm`、`llmEnabled=true`；还要观察正常操作时 `fallbackCount` 不持续增加。`llmEnabled=true` 只证明配置已启用，**实际调用成功仍需结合降级计数和业务结果判断**。

## 建议演示路径

1. 林奶奶登录，选择“上学的日子”，分段录音。
2. 每段录音经腾讯云转写后，对照只读原始转写和 Agent 建议，由林奶奶人工修改、确认并保存碎片。
3. 观察采访提示随内容变化；小刘登录后可以校对碎片，但不改变讲述者身份。
4. 勾选同一讲述者的已确认碎片，分别试用“原味口述”和“适合成书”；查看故事的逐句证据。
5. 故意加入一条原声未提到的事实，观察审计阻止确认；删去无依据句或继续补充讲述。
6. 由小刘或同家庭其他成员处理建议并确认故事。新生成的两类故事都经过 LangGraph 人工确认点及故事证据复审；早期无 checkpoint 草稿仍可通过兼容的证据复审入口。真机演示前仍需完整走通一次发布。
7. 打开“故事 → 家庭纪念册”，从封面左右滑动翻页，依次查看目录、按记忆年份升序排列的章节和各成员故事；点击“导出 PDF 纪念册”，下载并在微信中打开。年份未确认的故事放在末尾；长故事会分页，正文原字保留。内页水彩插图仅作装饰，不描绘或补造讲述事实。

## 已知限制与阶段边界

- 故事确认仍依赖后端可连接，并且正文通过逐句证据复审；未通过时草稿保留，可修改或继续补充讲述。
- 家庭纪念册现已支持已确认故事的时间线编排、左右翻页、复制全文和 PDF 导出。PDF 使用固定 A5 模板与静态装饰插画；书名修改目前只保存在当前设备、按家庭隔离。动态插画、家庭回忆录编辑 Agent、美术编排 Agent 仍未实现。
- “撤回授权并删除内容”按钮已从客户端移除；后端旧接口仍留兼容，不要在演示中调用。纪念册分享入口尚未开发，不等同于导出的 PDF。
- 家庭邀请接受/拒绝、真实短信、RAG、账号找回、头像上传、可见范围和公网部署不属于当前已完成功能。
- 模型输出经过 Pydantic / JSON Schema 与本地证据规则校验，但自动审计不能替代长辈核对原声和事实。
