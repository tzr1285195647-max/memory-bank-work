## 4. 布局与组件规律

- **内容边距**：左右各 24px，内容宽 342px（390 − 24×2）。
- **主按钮 / 输入框**：342×52，圆角 **12 / 14 / 16**（实测三档，非胶囊形），主按钮底色 `#4E6657` + 白字 17px Bold 居中；输入框白底。
- **卡片与列表项**：342 宽，圆角随高度递增 —— 82–94 高用 **18**，104–118 高用 **20**，148 高用 **24**，220–250 高的大卡用 **28**，310 高的故事卡用 **20**。
- **统计小卡（10 屏）**：100×82，圆角 **16**；头像 60×60 圆角 **30**（正圆）。
- **进度条**：342×12 与 226×12，圆角 **6**（半高胶囊）。
- **顶栏**：390×92，直角（rx=0），左品牌名 24px Bold 白色，右侧 `⋯`。
- **底部导航（04 / 08 / 09 / 10）**：390×76 直角贴底、白底，四栏 —— 首页 ⌂ / 讲述 ◉ / 故事 ▤ / 我的 ◎，图标 20px + 标签 11px，选中态 `#4E6657`，未选中 `#747A73`。
- **录音暂停键**：106×106 圆角 53（正圆），底色 `#4E6657`，白色 Ⅱ 图标 30px。

## 5. 与产品规则的对应（重要）

设计已经体现了文档里几条硬规则，实现时不要退化：

1. **来源标注可见**：07 故事预览用 `#C98362` 标出「原声 03:42　自然整理」——原声时长与整理方式对用户可见，是证据可追溯的界面表达。
2. **先预览后确认**：07 明确写“确认后，这段故事会保存到你的故事书”，并有「确认故事」按钮；没有自动保存路径。
3. **家人确认边界**：08 家庭看板出现「待家人确认 · 昨天」，与“发布需老人和创建者确认”一致。
4. **老人端优先**：04/05/06 用大字号（25–34px）、超大按钮（52–106px 高）、每屏只做一件事；长辈端顶栏用浅绿区分。
5. **一次只讲一个故事**：04 首页副标题写明“一次只讲一个小故事，不用从出生讲起”，对应追问策略。

## 6. 尚未在设计中出现（后端需补齐的界面）

- **七要素结构化展示**：设计里是自然段叙述（07），没有显式的“时间/地点/人物/事件/结果/影响/感受”字段视图。
- **AI 整理标识**：07 的“自然整理”是弱标注，产品规则要求“AI 生成或整理必须显式标注”，建议补一个更明确的「AI 整理 · 待确认」标签。
- **撤回授权入口**：设计里没有撤回/删除授权的界面，而这是产品规则中的硬要求。
- **追问交互**：Agent 追问（温和、至多一条）没有对应界面，目前只有 06 录音与 07 预览。
- **顶栏配色不一致**：长辈端 04/05 用浅绿 `#819276`，06 录音却用陶土红 `#C98362`；09 故事书也用陶土红。若“顶栏颜色代表身份”是设计意图，需要统一；若颜色代表状态（录音中），则 09 需要复核。
- **输入校验与错误态**：03 登录只有占位文案，没有错误提示、验证码倒计时等状态。
- **空状态**：09 故事书写死“8 个故事”，没有首次使用的空态设计。

## 7. 原始文件与解析方法

- 原始设计稿备份在工作区外：`D:\记忆银行-design-source\记忆银行 UI｜前端页面导入.fig`
- 解析脚本：`design/source/extract.mjs`（Kiwi 解码 → 节点树 → SVG → PNG），依赖 `kiwi-schema` 与 `@resvg/resvg-js`
- 中间产物：`design/source/canvas.fig`（从 .fig 容器解出的画布数据）、`node-outline.txt`（220 个节点的完整层级与文本）
- 预览图：`design/png/*.png`（由节点坐标重建，非 Figma 原生导出，字体 fallback 与原稿略有差异）
